# 🛒 E-Commerce Sales & Profit Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to understand revenue, profit, products, customers, geography, order behavior, and business performance.

The project combines SQL-based business analysis with an interactive sales dashboard to transform raw e-commerce data into meaningful analytical insights.

---

## 🎯 Project Objectives

- Analyze overall sales and profit performance
- Identify high-performing products and categories
- Understand customer purchasing behavior
- Analyze regional and geographical performance
- Study order trends and order status
- Answer business questions using SQL
- Present key findings through an interactive dashboard

---

## 🛠️ Tools & Technologies

- SQL
- Power BI / Dashboard Visualization

## 🗄️ SQL Analysis

The project includes a structured SQL analysis covering **52 business questions**.

The analysis covers areas including:

- Revenue analysis
- Product performance
- Customer analysis
- Customer segmentation
- Geographic analysis
- Order behavior
- Growth trends
- Order status analysis

Advanced SQL techniques used in the project include:

- Common Table Expressions (CTEs)
- Window Functions
- RFM Customer Segmentation
- Running Totals
- Conditional Aggregation
- Market Basket Analysis

## 📈 Key Business Questions

Some of the business questions addressed in the project include:

1. What is the total revenue?
2. What is the total profit?
3. Which products generate the highest sales?
4. Which products generate the highest profit?
5. Which regions perform best?
6. How does sales performance change over time?
7. Which categories contribute most to sales?
8. Which customers have the highest value?
9. What are the order-status patterns?
10. Which products or categories require further analysis?
